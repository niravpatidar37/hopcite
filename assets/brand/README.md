# hopcite brand assets

The mark is a **two-hop path**: three entity nodes joined by hop arcs, climbing to an answer
node with a citation ring. It reads as *follow the graph, then cite where you landed*.

| File | Use |
|---|---|
| `logo.svg` / `logo-dark.svg` | Lockup (mark + wordmark) for light / dark backgrounds. README header. |
| `icon.svg` / `icon-dark.svg` | Mark alone, transparent background. |
| `favicon.svg`, `favicon-32.png` | Browser tab / docs favicon (own ink tile, works on light and dark tabs). |
| `favicon-16.svg`, `favicon-16.png` | Hand-hinted 16 px variant (straight hops, pixel-centred nodes). |
| `avatar.svg`, `avatar-512.png` | Opaque square avatar (social / org). |
| `social-preview.png` (from `social-preview.svg`) | Repository social preview (Settings → Social preview), 1280×640, opaque. |

## Colors

| Token | Hex | Contrast | Use |
|---|---|---|---|
| Ink | `#0A1220` | 18.75:1 on `#FFFFFF` | Mark and wordmark on light backgrounds; tiles |
| Snow | `#EEF2F6` | 16.82:1 on `#0D1117` | Mark and wordmark on dark backgrounds |
| Teal (light) | `#0F766E` | 5.47:1 on `#FFFFFF` | Answer node and "cite" on light backgrounds |
| Teal (dark) | `#2DD4BF` | 10.17:1 on `#0D1117` | Answer node and "cite" on dark backgrounds |
| Slate | `#94A3B8` | 7.31:1 on Ink | Secondary text on the social preview |

The build script computes these ratios against GitHub's light (`#FFFFFF`) and dark (`#0D1117`)
backgrounds and fails below WCAG's 3:1 minimum for graphics.

## Usage

- Keep clear space around the lockup of at least the answer node's ring diameter.
- Below 120 px wide, use the mark alone; below 24 px, use the favicon variants.
- Do not recolor, stretch, rotate, outline, add effects, or set the wordmark in another font.

## Rebuilding

All assets are generated by `tools/build_brand.py`:

```sh
cargo install resvg --locked --version 0.48.1   # PNG export
uv run assets/brand/tools/build_brand.py
```

The script fetches Space Grotesk from a pinned `google/fonts` commit, verifies its SHA-256,
instances the variable font at Bold (700) and Medium (500), outlines all text, checks color
contrast, rejects any SVG containing scripts, event handlers, `foreignObject` or external
references, and renders the PNGs with resvg.
